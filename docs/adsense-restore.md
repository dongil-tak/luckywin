## 2. 복구 방법

가장 간단한 경로는 되돌리기 커밋입니다.

```bash
git revert aff0e74
```

수동으로 하려면 세 가지를 되살립니다.

**(1) `frontend/index.html` — `</head>` 앞에 추가**

```html
<!-- Google AdSense -->
<meta name="google-adsense-account" content="ca-pub-4554368744270377" />
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-4554368744270377"
 crossorigin="anonymous"></script>
```

**(2) `frontend/public/ads.txt` 재생성**

```
google.com, pub-4554368744270377, DIRECT, f08c47fec0942fa0
```

**(3) `AdSenseBanner` 컴포넌트 복원**

`git show aff0e74^:frontend/src/components/AdSenseBanner.tsx` 로 원본을 꺼낼 수 있습니다.
제거 시점에 이 컴포넌트는 **어디서도 임포트되지 않는 상태**였으므로, 되살린 뒤 게재 위치를 새로 정해야 합니다.

## 4. 승인 후 설정

- **광고 카테고리 차단** — 애드센스 콘솔에서 도박·복권 카테고리를 차단합니다.
  대출은 도박이 아니므로 차단 대상에서 제외하되, 약탈적 사금융은 자진 차단합니다.
- **RPM 실측** — 복권 콘텐츠는 Google 게시자 제한사항에 해당해 입찰 광고주가 줄어듭니다.
  한국 복권 광고주는 국영·정부라이선스 법인으로 제한되어 광고주 풀 자체가 좁으므로, 구조적 저RPM을 전제로 1개월 실측 후 판단하십시오.
